# Asset attribution

The simulator embeds one third-party asset. Its license is separate from the
`AGPL-3.0-or-later` license that covers the source code.

## images/ship.png

The ship sprite is a raster derivative of one of the vector ships in the
*Top down spaceships* set.

| | |
|---|---|
| Author | arin48 |
| Source | <https://opengameart.org/content/top-down-spaceships> |
| License | [Creative Commons Attribution 4.0 International (CC-BY 4.0)](https://creativecommons.org/licenses/by/4.0/) |
| Changes | One `ship_*.svg` from the set, rasterised to a 908x756 PNG with an alpha channel |

CC-BY 4.0 permits redistribution, including inside a binary and for commercial use,
and requires attribution. It sets no share-alike or non-commercial condition, so it
places no restriction on the AGPL-3.0-or-later license of the surrounding code.

The sprite is compiled into the executable, so this notice travels with every release
artifact and appears in the **About** tab of the simulator. Keep it in place if you
redistribute a build.
