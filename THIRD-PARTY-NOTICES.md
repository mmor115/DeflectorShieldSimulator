# Third-party notices

The `deflector-shield-simulator` and `manual` binaries statically link a number of Rust
crates. Some of those crates are distributed under licenses (MIT, Apache-2.0, BSD,
ISC and others) that require their copyright and license notices to be reproduced
alongside the binary. This file collects those notices.

The generated section below is produced by [`cargo about`](https://github.com/EmbarkStudios/cargo-about)
and is regenerated by CI on every release, so it always reflects the dependency set of
the build it ships with. Do not hand-edit the generated section; it will be overwritten.
To regenerate it locally, run:

```sh
cargo about generate about.hbs -o THIRD-PARTY-NOTICES.md
```

This file ships inside every release artifact (next to the executable), so that the
notices travel with the binary and not only with the source repository.

## Assets and fonts

The items below are not Rust crates, so `cargo about` does not see them. They are
recorded here by hand, and this section is not regenerated.

### Ship sprite

The simulator embeds one third-party image asset, `crates/simulator/assets/images/ship.png`.
It is a rasterised derivative of one of the vector ships in the *Top down spaceships*
set by **arin48**, sourced from
<https://opengameart.org/content/top-down-spaceships> and licensed under
[Creative Commons Attribution 4.0 International (CC-BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
One `ship_*.svg` from the set was rasterised to a 908x756 PNG with an alpha channel.
CC-BY 4.0 permits this use, including inside a binary and for commercial use, and
requires attribution, which is what this notice provides. See
`crates/simulator/assets/ATTRIBUTION.md` for the full attribution as it also appears in
the simulator's **About** tab.

### Latin Modern Math fonts

The documentation site generated by `crates/manual` renders mathematics with the
Latin Modern Math font family, vendored under `crates/manual/theme/math/`. These fonts
are distributed under the [GUST Font License](https://www.gust.org.pl/projects/e-foundry/lm-math/GUST-FONT-LICENSE.txt),
a license specific to fonts from the GUST e-foundry. It permits embedding and
redistribution of the fonts, including in web pages, and requires this notice.

### deflector-core

The `deflector-core` crate (<https://github.com/lucass-carneiro/DeflectorShields>)
provides the physics of the deflector-shield spacetime. It is licensed AGPL-3.0, the same
copyleft terms as this project, and is statically linked into every binary released here.
